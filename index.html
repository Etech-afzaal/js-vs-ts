Can browsers run TypeScript directly?

Click both buttons. The first executes regular JavaScript. The second asks the browser's JavaScript parser to execute TypeScript syntax without a compiler.

Prediction:

JavaScript executes successfully. TypeScript-only syntax such as : number produces a SyntaxError in a standard JavaScript parser.

JavaScript

Runs directly ✓

Native syntax understood by the browser's JavaScript engine.

function add(a, b) {
  return a + b;
}

console.log(add(5, 10));
Click “Run JavaScript” to see the result.

TypeScript

Not directly executable ✕

Type annotations are TypeScript syntax, not standard JavaScript syntax.

function add(a: number, b: number): number {
  return a + b;
}

console.log(add(5, 10));
Click “Run TypeScript directly” to test the raw code.
